Responsive Coffee Shop Website Design Coffee Shop Website ☕ (HTML, CSS, JavaScript)

A fully responsive multi-page Coffee Shop website built using HTML5, CSS3, and JavaScript.
The project focuses on clean UI design, responsive layouts, and smooth user interactions.

🔧 Features
1. Fully responsive design for desktop, tablet, and mobile.
2. Interactive UI components using vanilla JavaScript.
3. Smooth navigation with optimized DOM functions.
4. Menu page, About page, Contact page, and Home page included.
5. Clean and modern UI/UX layout.

🛠 Tech Stack
1. HTML5
2. CSS3
3.JavaScript

📌 What I Learned
1. Structuring multi-page websites.
2. Writing clean and reusable CSS for responsiveness.
3. Enhancing UX with JavaScript interactivity.
